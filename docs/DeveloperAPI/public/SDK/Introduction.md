The Blitz Gateway SDK is a lightweight and developer-friendly Python library designed to simplify integration with the Blitz Gateway API. It allows traders and developers to easily access market data, execute trades, and interact with the Blitz ecosystem through clean and efficient APIs.

### Key Feature

- **Easy Integration**: Connect to the Blitz Gateway API in just a few lines of code.
- **Real-Time Market Data**: Stream live quotes, tick data, and market depth updates.
- **Trading APIs: Place**, modify, and cancel orders seamlessly.
- **Secure Authentication**: Token-based authentication ensures safe access.
- **WebSocket Support**: Subscribe to live data feeds using an asynchronous WebSocket client.
- **Comprehensive Logging**: Built-in logging for better debugging and monitoring.
- **Lightweight Design**: Minimal dependencies and fast performance.

### Getting Started

#### Step 1: Prerequisites
Before you begin, ensure you have the following installed:

- Python 3.8 or above
- `pip` (Python package manager)
- A valid Blitz Gateway account

#### Step 2: Generate Api Key
Trader can generate their **Api key** credintial from **Blitz Gateway Portal** 

#### Step 3: Install SDK
`pip install blitz-sdk`
